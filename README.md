# Endermonks Portfolio

> We Build Digital Empires — a Framehaus-inspired portfolio for the Endermonks dev team.

Built with **React 18** + **Tailwind CSS 3**.

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm start

# Build for production
npm run build
```

## Project Structure podahuttek buruwek

```
src/
├── components/
│   ├── Cursor.jsx      # Custom cursor (desktop)
│   ├── Navbar.jsx      # Sticky navigation
│   ├── Hero.jsx        # Full-screen hero
│   ├── Ticker.jsx      # Scrolling services ticker
│   ├── Services.jsx    # Services list with hover
│   ├── Projects.jsx    # Project grid with overlays
│   ├── Stats.jsx       # Key numbers (white section)
│   ├── Team.jsx        # Team member cards
│   ├── Stack.jsx       # Tech stack grid
│   ├── Contact.jsx     # Contact form + socials
│   └── Footer.jsx      # Footer
├── hooks/
│   └── useReveal.js    # Scroll-triggered reveal hook
├── App.jsx
├── index.js
└── index.css           # Tailwind + custom animations
```
